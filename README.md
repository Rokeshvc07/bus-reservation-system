# 🚌 Bus Reservation System

A full-stack Bus Reservation System built with Flask, Python, and SQLite.

## ✨ Features

- User Registration & Login
- Search Available Buses
- Seat Booking
- View My Bookings
- Cancel Booking
- Reschedule Booking
- User Profile
- Admin Dashboard

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2

## 📂 Project Structure

app/
├── static/
├── templates/
├── database.py
├── routes.py
└── __init__.py

run.py
config.json

## 🚀 Installation

1. Clone the repository
2. Install dependencies
3. Run:

python run.py
